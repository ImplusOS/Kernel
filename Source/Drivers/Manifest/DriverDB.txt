# DriverDB.txt -- bus device id -> on-demand driver module manifest.
# Read at runtime by Kernel/Drivers/Module/DriverDB.c when BusRegistry.c
# finds no already-loaded module claiming an enumerated device. Hand
# maintained -- see the comment at the top of DriverDB.c for why, and the
# format this file follows.
#
# Entries below name files staged under Kernel/Driver/OnDemand/ (see the
# top-level Makefile), never Kernel/Driver/ itself -- that directory is
# swept by the bootloader's preloader at boot and would defeat the point
# of loading these only when actually needed.

# AICSemi AIC8800D80 USB Wi-Fi -- Kernel/Drivers/Wi-Fi/AIC8800/
# No pid= filter: units enumerate under several product ids depending on
# what the on-board firmware is doing (the loader stage shows up as one
# pid, the full-mac driver as the next), and AIC8800.c's own
# bus_matches[] (Kernel/Drivers/Wi-Fi/AIC8800/AIC8800.c) matches on
# vendor id + vendor-specific interface class only, treating the pid in
# probe() -- keep this on-demand manifest consistent with that rather
# than hardcoding one pid that would miss half the states the dongle
# goes through.
usb:vid=A69C=AIC8800_Driver.ELF
usb:vid=368B=AIC8800_Driver.ELF
